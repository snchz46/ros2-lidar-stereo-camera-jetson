
# 🤖 Automotive Systems Master Project 2025: ADMIT14 ROS 2 
> A project work by Samuel Sanchez, Master student at Hochschule Esslingen
##  Repository guide

Welcome to this practical and compact guide about ROS 2 and how to implement and integrate an RPLiDAR and a Stereo Camera on a NVIDIA Jetson Nano. 

This project is offered to ASM students at Esslingen University. The work continues predecessor projects and has interfaces to other project teams. 

The theoretical foundation underlying this project is part of a broader research project named Automated Driving in Miniaturized Traffic scenarios 1:14 (ADMIT14), which are intended to validate autonomous driving technology in a controlled, small-scale environment.

## Automated Jetson Nano setup

The repository includes an automated installer that prepares a Jetson Nano running Ubuntu 20.04 for ROS 2 Foxy.

### Prerequisites

- Run the script as `root` (either log in as `root` or prefix the command with `sudo`).
- Ensure the Jetson Nano has Internet connectivity and enough free disk space for ROS 2.

### Run the installer

```bash
cd /path/to/ros2-lidar-stereo-camera-jetson
sudo ASSUME_YES=true ./Scripts/setup/jetson_install.sh
```

By default, the script prompts for confirmation. Set `ASSUME_YES=true` to run non-interactively (useful for CI or unattended provisioning).

### Optional environment variables

| Variable | Purpose |
| --- | --- |
| `ASSUME_YES=true` | Skip the confirmation prompt and run with `DEBIAN_FRONTEND=noninteractive`. |
| `ROS2_TARGET_USER=<username>` | Specify which account should source `/opt/ros/foxy/setup.bash` in its `.bashrc`. Defaults to the invoking non-root user or `root`. |
| `ROS2_LOCALE=<locale>` | Set the locale generated by the script (default: `en_US.UTF-8`). |
| `LOG_DIR=/custom/path` | Store installer logs in a different directory (default: `Scripts/setup/logs`). |

The installer writes detailed logs to `Scripts/setup/logs/jetson_install_<timestamp>.log` and can be re-run safely thanks to idempotency checks for package installation, repository configuration, locale settings, and shell setup.

### Reproducible x86 developer environment (optional)

Developers on x86 hosts can build a ROS 2 Foxy container that mirrors the Jetson environment:

```bash
docker build -f Scripts/setup/Dockerfile.ros2-foxy-x86 -t ros2-foxy-dev .
docker run --rm -it ros2-foxy-dev
```

The Docker image installs ROS 2 Foxy, colcon extensions, and initializes `rosdep`, providing an isolated workspace that matches the Jetson dependencies.
